# Airmax Product Card UI 👟

A responsive and styled e-commerce product card component built with pure HTML5 and CSS3.

## 🌟 Overview
This project showcases a modern e-commerce product showcase card featuring:
- **Product Title & Brand Header**: Clean branding for Nike Airmax.
- **Pricing & Discounts**: Strikethrough original price display alongside discounted pricing.
- **Interactive Options**: Size selection guide and interactive color swatch indicators.
- **Call-to-Action Buttons**: Integrated "Buy Now" and "Add to Cart" actions.
- **Custom Visual Styling**: Curated typography, overlay badge graphics, and background contrast.

## 🛠️ Tech Stack
- **HTML5**: Semantic web structure.
- **CSS3**: Custom properties, positioning, background accents, and responsive styling.
